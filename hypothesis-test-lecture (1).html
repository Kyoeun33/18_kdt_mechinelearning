가설검정, 통계라는 이름의 재판

"이 결과, 진짜 의미가 있는 걸까 아니면 그냥 우연일까?" — 데이터를 다루다 보면 늘 마주치는 질문입니다. 이 질문에 원칙을 갖고 답하는 방법이 가설검정(Hypothesis Test)입니다. 통계를 한 번도 배운 적 없어도 괜찮습니다. 가설검정은 사실 우리에게 익숙한 장면과 구조가 똑같습니다 — 바로 법정 재판입니다.

예를 들어 이런 질문들이 모두 가설검정으로 판가름 납니다.

  • 새로운 광고가 정말 매출을 늘렸는가?
  • 새로운 약이 기존 약보다 정말 효과가 있는가?
  • 이 정책이 정말 효과가 있었는가?

법정에서 판사는 "느낌"이 아니라 증거로 유·무죄를 가립니다. 가설검정도 똑같습니다. "그럴 것 같다"는 감이 아니라, 데이터라는 증거로 결론을 내립니다. 지금부터 이 재판정의 등장인물과 진행 절차를 하나씩 살펴보겠습니다.

EXHIBIT A

가설검정이란 무엇인가Hypothesis Test

가설검정은 데이터를 근거로 어떤 주장이 맞는지 판단하는 통계 방법입니다. 어떤 결과가 그냥 우연히 나온 건지, 아니면 실제로 의미 있는 차이인지 헷갈릴 때 사용합니다.

이 방법을 쓰면 분석 결과가 통계적으로 의미 있는지를 판단할 수 있습니다.

법정 비유

판사는 "왠지 유죄일 것 같다"는 인상만으로 판결을 내리지 않습니다. 반드시 제출된 증거를 근거로만 판단합니다. 가설검정도 마찬가지로, "차이가 있는 것 같다"는 직관이 아니라 데이터라는 증거를 기준으로 결론을 내립니다.

EXHIBIT B

귀무가설 vs 대립가설H0 & H1

재판이 시작되려면 먼저 "무슨 혐의로 재판하는지"부터 정해야 합니다. 가설검정도 항상 두 가지 가설을 먼저 세우는 것부터 시작합니다.

귀무가설 H0
차이가 없다 / 효과가 없다 / 변화가 없다 — 무죄 추정과 같은 기본 전제
대립가설 H1
차이가 있다 / 효과가 있다 / 변화가 있다 — 검사가 새로 입증하려는 주장

신약 실험 예시 — 귀무가설: 새로운 약은 기존 약과 효과 차이가 없다 / 대립가설: 새로운 약이 기존 약보다 더 효과가 있다.

검사(대립가설 쪽)는 법정에서 자기 주장을 처음부터 끝까지 스스로 "증명"하지 않습니다. 대신 "무죄 추정을 뒤집을 만큼 확실한 증거가 있는가"만 따집니다. 가설검정도 똑같습니다 — 대립가설을 직접 증명하는 게 아니라, 귀무가설을 기각할 수 있는지를 판단하는 방식으로 진행됩니다.
이미지 속 시험 출제 포인트
  • 귀무가설 H0 의미
  • 대립가설 H1 의미
  • 가설검정은 귀무가설 기각 여부 판단
EXHIBIT C

유의수준Significance Level, α

유의수준(α)은 귀무가설을 기각할 기준이 되는 확률입니다. 즉 귀무가설이 실제로 맞는데도 틀렸다고 오판할 수 있는 최대 허용 확률을 뜻합니다.

일반적으로 α = 0.05 (5%)를 사용합니다.

법정 비유

재판이 시작되기 전, 판사는 스스로에게 이렇게 다짐합니다. "이 정도로 확실한 증거가 아니면 무죄 추정을 뒤집지 않겠다." 이게 바로 유의수준입니다. α=0.05라는 건 "100번 재판하면 5번 정도는 억울한 판결이 나올 수 있음을 미리 감수하겠다"는, 판사가 사전에 정해두는 엄격도 기준입니다.

헷갈리기 쉬운 짝 — 신뢰수준 vs 유의수준
신뢰수준(Confidence Level)은 "판결을 얼마나 확신하고 싶은가"(예: 95%)이고, 유의수준(α)은 "몇 %까지는 오판을 감수하겠는가"(예: 5%)입니다. 즉 신뢰수준 + 유의수준 = 100%인, 서로 반대말 같은 짝입니다. 신뢰수준을 99%로 더 엄격하게 잡으면(=유의수준을 1%로 낮추면), 판사는 웬만한 증거로는 무죄 추정을 뒤집지 않게 됩니다.
이미지 속 시험 출제 포인트
  • 유의수준 = α
  • 일반적으로 0.05 사용
  • 1종 오류 확률과 동일
  • 신뢰수준 + 유의수준 = 100%
EXHIBIT D

p-valueProbability Value

p-value는 귀무가설이 맞다고 가정했을 때, 지금과 같은 데이터 결과가 나타날 확률입니다. 즉 데이터가 귀무가설과 얼마나 모순되는지를 보여주는 값입니다.

p-value ≥ α
귀무가설 채택 — 무죄 추정 유지
p-value < α
귀무가설 기각 — 통계적으로 의미 있는 결과

예시 — p-value = 0.03, 유의수준 α = 0.05라면, 0.03 < 0.05이므로 귀무가설을 기각합니다.

법정 비유

p-value는 "증거의 신빙성 점수"라고 생각하면 됩니다. "피고인이 정말 무죄라면, 이런 증거가 우연히 나올 확률이 얼마나 될까?"를 숫자로 매긴 것입니다. 이 확률이 아주 낮다면(p < α), "무죄인 사람에게서 나오기엔 너무 수상한 증거"라는 뜻이 되어 유죄(기각) 쪽으로 판결이 기웁니다.

또 다른 사건 기록 — 타이타닉 Parch 변수
머신러닝에서 자주 쓰는 타이타닉 데이터로 "동승한 부모·자녀 수(Parch)가 생존 여부에 영향을 주는가"를 검정하면 p-value = 0.073이 나옵니다. 유의수준 α = 0.05와 비교하면 0.073 > 0.05이므로 귀무가설을 기각하지 못합니다 — 즉 "Parch가 생존에 영향을 준다"고 단정하기는 어렵다는 뜻입니다. 증거(p-value)가 살짝 부족해서 무죄 추정을 뒤집지 못한 셈입니다.

  • p-value 의미
  • p-value와 유의수준 비교
  • p-value < α → 귀무가설 기각
EXHIBIT E

1종 오류Type I Error

1종 오류는 귀무가설이 실제로 맞는데 기각하는 오류입니다. 실제로는 차이가 없는데, 차이가 있다고 잘못 판단하는 경우로, False Positive라고도 부릅니다.

예시 — 신약이 실제로는 효과가 없는데, 실험 결과에서는 효과가 있다고 결론 내리는 경우.

1종 오류의 확률은 유의수준 α와 동일합니다.

법정 비유

1종 오류는 실제로 무죄인 사람을 유죄로 오판하는 것, 즉 억울한 옥살이입니다. 통계 분석에서는 이런 오류를 최소화하려고 유의수준(α)을 미리 엄격하게 정해둡니다. 다만 판사가 너무 신중해지면(α를 낮추면), 이번엔 진범을 놓치는 문제가 생길 수 있습니다 — 다음 증거물에서 이어집니다.

이미지 속 시험 출제 포인트
  • 1종 오류 = 귀무가설이 맞는데 기각
  • False Positive
  • 1종 오류 확률 = 유의수준 α
EXHIBIT F

2종 오류Type II Error

2종 오류는 귀무가설이 실제로 틀렸는데 기각하지 못하는 오류입니다. 실제로는 차이가 있는데, 차이가 없다고 판단하는 경우로, False Negative라고 부릅니다.

2종 오류의 확률은 보통 β(베타)로 표현하며, 다음 개념과 이어집니다.

검정력 Power
1 − β — 검정력이 높을수록 2종 오류가 발생할 가능성은 낮아집니다.

법정 비유

2종 오류는 진범을 무죄로 방면하는 것입니다. 판사가 너무 신중한 나머지 확실한 증거만 인정하다 보면, 정작 진짜 유죄인 사람을 놓칠 수 있습니다. 반대로 검정력은 "진범을 진범이라고 정확히 잡아내는 수사력"이라 할 수 있습니다. 즉 1종 오류(억울한 판결)를 줄이는 것과 2종 오류(진범을 놓치는 것)를 줄이는 것은 늘 시소처럼 균형을 잡아야 하는 관계입니다.

이미지 속 시험 출제 포인트
  • 2종 오류 = 귀무가설이 틀렸는데 채택
  • False Negative
  • 2종 오류 확률 = β
EXHIBIT G

검정 통계량Test Statistic

검정 통계량은 가설검정을 수행할 때 데이터로부터 계산되는 통계값입니다. 이 값을 이용해 p-value를 계산하고, 귀무가설을 기각할지 판단하게 됩니다. 흐름은 이렇습니다.

계산 흐름
검정 통계량 → p-value 계산 → 가설 판단

법정 비유

검정 통계량은 흩어진 증거들을 하나의 감정 점수로 환산한 결과라고 보면 됩니다. 그리고 사건의 성격에 따라 쓰는 감정 도구가 다르듯, 통계에도 상황별로 다른 검정 방법이 있습니다.

Z 검정

t 검정
모집단 분산을 모를 때 평균을 비교 — 표본 자체로 추정해야 하는 상황의 감정
카이제곱 검정

분산 비교 또는 분산분석(ANOVA) — 여러 집단의 편차를 한꺼번에 비교하는 방식

EXHIBIT H

가설검정 과정Hypothesis Testing Process

가설검정은 일반적으로 아래 5단계로 진행됩니다. 이 순서를 실제 재판 진행 절차에 그대로 겹쳐 보면 왜 이런 순서인지 자연스럽게 이해됩니다.

  1. 귀무가설(H0)과 대립가설(H1) 설정

    검사와 변호인이 각자의 입장을 정리하는 단계

  2. 유의수준 설정 (보통 α = 0.05)

    판사가 오판을 허용할 기준을 미리 공표하는 단계

  3. 검정 통계량 계산

    증거를 감정해 하나의 점수로 만드는 단계

  4. p-value 계산

    그 증거의 신빙성을 확률로 수치화하는 단계

  5. 가설 판단 — p < α → 기각 / p ≥ α → 채택

    최종 판결을 선고하는 단계

이 과정을 통해 데이터 분석 결과가 통계적으로 의미 있는지를 판단할 수 있습니다.

Closing Statement

판결문 요약 — 가설검정 핵심 정리

가설검정은 데이터 분석에서 통계적 유의성을 판단하는 핵심 방법입니다. 빅데이터분석기사 필기 시험에서는 아래 개념이 특히 자주 출제됩니다.

  • 귀무가설 (H0)차이가 없다 / 효과가 없다 — 무죄 추정
  • 대립가설 (H1)차이가 있다 / 효과가 있다 — 검사의 주장
  • 유의수준 (α)보통 0.05 사용, 오판을 허용하는 최대 기준
  • p-valuep < α → 귀무가설 기각
  • 1종 오류귀무가설이 맞는데 기각 — False Positive
  • 2종 오류귀무가설이 틀렸는데 채택 — False Negative
  • 가설검정 절차가설 설정 → 유의수준 설정 → 검정통계량 계산 → p-value 계산 → 가설 판단

통계 파트를 공부하실 때 위 개념을 정리해 두시면 시험 대비에 큰 도움이 됩니다.

EXHIBIT I

정규성 검정과 p-value, 다시 보기Normality Test

많은 통계 검정은 "증거가 정규분포(좌우 대칭한 종 모양)를 따른다"는 전제 위에서 이뤄집니다. 그래서 감정사는 본격적인 감정에 앞서, 이 증거가 애초에 '정상적인 형태'를 갖췄는지부터 확인합니다. 이를 정규성 검정이라 하며, 가장 널리 쓰이는 방법이 Shapiro-Wilk 검정입니다.

감정 기록 — PCB 기판 두께 15개를 샘플링해 정규성을 확인합니다. 귀무가설은 "이 데이터는 정규분포를 따른다"입니다.
python
data = np.array([119, 110, 108, 120, 117, 109, 96, 104, 123, 113, 129, 106, 93, 92, 102])

stats.shapiro(data)
ShapiroResult(statistic=0.9715, pvalue=0.8799)

p-value(0.8799)가 유의수준(0.05)보다 훨씬 크므로, 귀무가설을 기각할 수 없습니다. 즉 "정규성을 만족하지 않는다"고 볼 수 없으므로, 이 데이터는 정규하다고 판단합니다. (반대로 p-value가 0.05보다 작았다면 "정규하지 않다"고 판단합니다.)

법정 비유 — 오락실 뽑기 사건

어느 오락실 사장이 "뽑기 1~4등은 모두 공평하게 25%"라고 홍보합니다. 그런데 손님이 뽑기 10개를 뽑았더니 전부 4등만 나왔습니다. 사장님 말을 믿을 수 있을까요? 대부분은 "그 기계, 공평하지 않다"고 의심할 겁니다. 정말로 공평한 기계라면 4등만 10번 연속 나올 확률이 너무 희박하기 때문입니다.

그런데 이 의심에는 함정이 하나 있습니다. 기계가 진짜로 공평했는데, 그저 재수 없게 4등만 연속으로 나왔을 가능성도 0은 아니라는 점입니다. 바로 이 "재수 없게 틀렸을 확률"이 p-value입니다. 판사가 유죄를 선고해도, 사실은 무죄인 사람에게 극히 드문 우연이 겹쳐서 그렇게 보였을 가능성은 완전히 배제할 수 없습니다 — 모든 통계적 판결은 이 리스크를 안고 내려집니다.

추가 예제 — 시험 점수 12개 [75, 83, 81, 92, 68, 77, 78, 80, 85, 95, 79, 89]가 정규분포를 따르는지 확인합니다.
python
stats.shapiro([75, 83, 81, 92, 68, 77, 78, 80, 85, 95, 79, 89])
W ≈ 0.977, p-value ≈ 0.968 → 0.968 ≥ 0.05, 귀무가설 기각 못함 → 이 데이터는 정규분포를 따른다고 볼 수 있음
실습 핵심 정리
  • 정규성 검정 = Shapiro-Wilk
  • 귀무가설: 정규분포를 따른다
  • p-value = 재수 없게 틀렸을 확률
  • 신뢰수준 ↔ 유의수준(반대 개념)
EXHIBIT J

중심극한정리와 Z·t검정CLT & Z/t-test

모집단 전체를 조사할 수 없을 때, 감정사는 표본 몇 개만으로 모집단의 평균을 추정해야 합니다. 이를 가능하게 해주는 원리가 중심극한정리(CLT)입니다.

모집단의 분포 모양과 상관없이, 표본 크기 n이 충분히 커지면 표본평균의 분포는 정규분포 N(μ, σ²/n)에 가까워집니다. 통상 n이 30 이상이면 정규분포로 근사해 취급합니다.

Z 검정
모집단의 분산(σ²)을 알고 있을 때 사용
t 검정
모집단 분산을 몰라 표본 분산으로 대체 — 대신 자유도를 n−1로 보정

자유도(degree of freedom)란 "자유롭게 움직일 수 있는 변수의 개수"입니다. 모르는 모분산을 표본 분산으로 "아는 척" 대체했기 때문에, 그 대가로 자유도에서 1을 빼줍니다. 자유도 = 표본 개수 − 제약조건 개수

감정 기록 — PCB 기판 두께 15개 표본으로, 모평균이 110인지 검정합니다. 귀무가설은 "평균은 110이다"이며, 모분산을 모르므로 t검정을 사용합니다.
python
data = np.array([117, 110, 109, 119, 117, 109, 103, 95, 123, 111, 125, 106, 92, 93, 105])

stats.ttest_1samp(data, popmean=110, alternative='two-sided')
TtestResult(statistic=-0.4009, pvalue=0.6946, df=14)

p-value(0.69)가 0.05보다 크므로 귀무가설을 기각하지 못합니다. 모평균은 110이라고 판단합니다.

양측검정 vs 단측검정 — "110과 다른지"를 볼 때는 정규분포 양쪽 꼬리 면적을 모두 p-value로 더하고(양측검정, alternative='two-sided'), "110보다 큰지/작은지"만 볼 때는 한쪽 꼬리 면적만 p-value로 씁니다(단측검정, alternative='greater' 또는 'less'). 법정으로 치면 "무죄가 아니다"만 볼지, "특정 방향(더 심하다/더 약하다)까지" 볼지의 차이입니다.

법정 비유 — t분포의 두꺼운 꼬리

t분포는 정규분포와 비슷한 종 모양이지만, 양쪽 꼬리가 더 두껍습니다(fat tail). 표본이 적을수록 평균에서 크게 벗어난 값이 나올 여지를 더 넉넉하게 열어두는 것이죠 — 경험이 적은 감정사가 "증거가 몇 개 안 되니 극단적인 결과가 나올 수도 있다"며 판단에 여유를 더 두는 것과 비슷합니다. 표본(자유도)이 늘어날수록 이 여유는 줄어들고, 자유도가 30 이상이면 t분포는 정규분포와 거의 같아집니다.

실습 핵심 정리
  • 중심극한정리: n↑ → 표본평균 분포는 정규분포에 근사
  • 모분산 알면 Z검정, 모르면 t검정
  • 자유도 = n − 1, t분포는 정규분포보다 꼬리가 두꺼움(fat tail)
  • 양측검정 vs 단측검정
EXHIBIT K

t검정 3종 실습1/2-sample & paired t-test

t검정은 비교하는 대상에 따라 세 가지로 나뉩니다. 세 건의 사건을 통해 차이를 비교해 봅니다.

1표본 t검정
표본 하나로 모평균을 추정 — "증거 하나로 전체를 가늠"
2표본 t검정
서로 다른 두 집단의 평균 비교 — "두 목격자의 증언 비교"
대응(쌍체) t검정
같은 대상의 전/후 비교 — "한 목격자의 사건 전후 진술 비교"

① 1표본 t검정 — PCB 두께가 110보다 작은지 단측 검정 (귀무가설: 평균은 110보다 작지 않다).

python
stats.ttest_1samp(data, popmean=110, alternative='less')
statistic=-0.4009, pvalue=0.3473, df=14 → 0.3473 ≥ 0.05, 귀무가설 기각 못함 → "110보다 작지 않다"고 판단

② 2표본 t검정 — 두 업체(A/B)에서 각 30개씩 샘플링한 PCB 두께의 평균 차이 검정 (귀무가설: 두 업체의 평균은 차이가 없다). 먼저 등분산성(Levene)을 확인합니다.

python
stats.levene(sample1, sample2)          # 등분산성 확인
stats.ttest_ind(sample1, sample2)       # 2표본 t검정
LeveneResult(pvalue=0.4163) TtestResult(statistic=-2.7565, pvalue=0.0078, df=58) → 0.0078 < 0.05, 귀무가설 기각 → 두 업체의 평균은 다르다고 판단

③ 대응(쌍체) t검정 — 학생 20명의 통계 교육 이수 전/후 시험 점수를 비교 (귀무가설: 전/후 평균은 차이가 없다).

python
stats.ttest_rel(before, after)
TtestResult(statistic=-3.6327, pvalue=0.00177, df=19) → 0.00177 < 0.05, 귀무가설 기각 → 교육 전/후 점수 차이가 있다고 판단

추가 예제 ① 1표본 t검정 — 학생 22명의 시험 점수 평균이 75점을 넘는지 단측 검정합니다(귀무가설: 평균은 75점을 넘지 않는다).

python
scores = [75, 80, 68, 72, 77, 82, 81, 79, 70, 74, 76, 78, 81, 73, 81, 78, 75, 72, 74, 79, 78, 79]

stats.ttest_1samp(scores, 75, alternative='greater')
표본평균 ≈ 76.46, t ≈ 1.766, p-value ≈ 0.046 → 0.046 < 0.05, 귀무가설 기각 → 평균은 75점을 넘는다고 판단 (경계에 아슬아슬하게 걸친 사례)
또 다른 판정법 — 임계값(Critical Value)
p-value 대신, 판사가 미리 정해둔 "기각선(임계값)"에 검정통계량이 넘어서는지로 판단할 수도 있습니다. 이 예제라면 자유도 21, 유의수준 5%(단측)의 임계값은 stats.t.ppf(0.95, df=21) ≈ 1.721. 실제 통계량 t≈1.766이 이 선을 넘었으므로 역시 기각 — p-value로 판단한 결론과 정확히 같습니다. 두 방법은 같은 재판을 다른 잣대(확률 vs 점수선)로 보는 것뿐입니다.
표본이 작거나 정규성이 깨졌다면 — 비모수 대안(Wilcoxon)
1표본·대응표본 t검정은 정규성이 흔들리면 Wilcoxon 부호순위검정으로 대신합니다. 값 자체가 아니라 차이의 순위를 사용하므로 극단치에 덜 흔들립니다.
python
from scipy.stats import wilcoxon
wilcoxon(scores_diff, alternative='greater')   # 1표본: 기준값과의 차이
wilcoxon(after, before, alternative='greater') # 대응표본: 전/후 비교

추가 예제 ② 독립표본 t검정 — 신약 투여군과 대조군 각 10명의 체온을 비교합니다(귀무가설: 두 군의 체온 평균은 차이가 없다).

python
group1 = [36.8, 36.7, 37.1, 36.9, 37.2, 36.8, 36.9, 37.1, 36.7, 37.1]   # 투여군
group2 = [36.5, 36.6, 36.3, 36.6, 36.9, 36.7, 36.7, 36.8, 36.5, 36.7]   # 대조군

stats.ttest_ind(group1, group2)
평균 36.93℃ vs 36.63℃, t ≈ 3.796, p-value ≈ 0.0013 → 0.0013 < 0.05, 귀무가설 기각 → 두 집단의 체온 평균은 유의미하게 다름
독립표본의 비모수 대안 — Mann-Whitney U검정
두 집단 중 하나라도 정규성을 만족하지 못하면, 값 대신 순위를 비교하는 Mann-Whitney U검정을 씁니다. Exhibit Q의 크루스칼-왈리스가 "3집단 이상의 비모수 버전"이라면, 이건 "2집단의 비모수 버전"인 셈입니다.
python
from scipy.stats import mannwhitneyu
mannwhitneyu(group1, group2, alternative='two-sided')
t검정은 표본이 정규성을 만족할 때 쓸 수 있으므로, 실제로는 먼저 정규성 검정을 거친 뒤 t검정을 수행하는 것이 원칙입니다. 대응표본 t검정도 방향을 지정하고 싶다면 alternative='less'(감소했는지) 또는 'greater'(증가했는지)를 지정할 수 있습니다 — 예: 치료 후 혈압이 내려갔는지만 보고 싶다면 ttest_rel(사후, 사전, alternative='less'). 독립표본 t검정은 추가로 두 집단의 분산이 같아야(등분산성) 하는데, 만약 등분산이 아니라면(Levene 검정 p < 0.05) ttest_ind(..., equal_var=False)로 바꿔 Welch's t-test를 사용합니다 — 두 감정사의 손떨림(분산) 정도가 다르다는 걸 알고도 그 차이를 보정해 비교하는 방식입니다.
실습 핵심 정리
  • 1표본 t검정 · 2표본 t검정 · 대응표본 t검정
  • 2표본 t검정은 등분산성(Levene) 선확인
  • 등분산이 아니면 Welch's t-test(equal_var=False)
  • t검정 전 정규성 검정이 원칙
EXHIBIT L

카이제곱 검정 실습 — 분산 감정Chi-squared Test

카이제곱(χ²) 통계량은 표본의 분산으로 모집단의 분산을 추정·검정할 때 사용합니다. (범주형 자료의 적합도·독립성 검정에도 쓰이지만, 여기서는 분산 검정에 집중합니다.)

χ²  =  (n−1) · s²  /  σ²
n — 표본 크기   s — 표본의 표준편차   σ — 모집단의 표준편차   자유도 = n−1
감정 기록 — PCB 두께 20개 표본으로, 모분산이 8보다 작은지 단측 검정합니다. 귀무가설은 "분산은 8보다 작지 않다(≥8)"입니다.
python
freedom = len(data) - 1
sample_var = np.var(data, ddof=1)
chi_stats = freedom * sample_var / 8

p_value = stats.chi2.cdf(chi_stats, freedom)
Chi-square statistic = 14.219, p-value = 0.2292 → 0.2292 ≥ 0.05, 귀무가설 기각 못함 → "분산이 8보다 작다"고 볼 수 없음
만약 "분산이 정확히 8인가?"를 묻는 양측검정이라면, stats.chi2.cdf(...)와 1 − stats.chi2.cdf(...) 중 더 작은 쪽 면적의 2배를 p-value로 사용합니다. 카이제곱 분포는 t분포·정규분포와 달리 좌우 대칭이 아니기 때문입니다.

법정 비유

지금까지는 증거의 "평균적인 값"을 감정했다면, 카이제곱 검정은 증거가 얼마나 들쭉날쭉한지(분산)까지 정밀하게 재는 감정입니다. 평균은 비슷해도 산포가 크게 다르면, 공정 자체의 안정성을 의심해볼 수 있습니다.

실습 핵심 정리
  • χ² = (n−1)s² / σ²
  • 표본 분산 → 모분산 추정/검정
  • 좌우 비대칭 분포 → 양측검정은 작은 면적×2
EXHIBIT M

F검정과 등분산성 검정F-test & Levene

F 분포는 두 카이제곱분포의 비율로 정의되는, 두 분산을 비교하기 위해 고안된 분포입니다. F 통계량이 두 집단의 분산이 같은지(등분산성)를 비교하는 핵심 도구이며, 회귀분석·분산분석(ANOVA)에서도 널리 응용됩니다.

F  =  (s₁²/σ₁²)  /  (s₂²/σ₂²)
s₁, s₂ — 두 표본 집단의 표준편차   σ₁, σ₂ — 두 모집단의 표준편차
두 카이제곱 통계량의 비율 U₁/ν₁ ÷ U₂/ν₂ 로도 표현되며, F ~ F(n₁−1, n₂−1) 분포를 따릅니다.
감정 기록 — 내수용·수출용 PCB 두께(각 20개)의 분산이 같은지 검정합니다. 귀무가설은 "두 분산은 차이가 없다"입니다.
python
F_stats = np.var(a_data, ddof=1) / np.var(b_data, ddof=1)
pvalue = min(stats.f.cdf(F_stats, df_a, df_b),
             stats.f.sf(F_stats, df_a, df_b)) * 2
F_stats = 0.2877, p-value = 0.0093 → 0.0093 < 0.05, 귀무가설 기각 → 대립가설(두 분산은 다르다) 채택

같은 데이터를 데이터가 정규분포가 아니어도 쓸 수 있는 Levene 등분산성 검정으로 다시 확인해도 결론은 같습니다.

stats.levene(a_data, b_data)
LeveneResult(statistic=7.3328, pvalue=0.0101) → F검정과 동일하게 "등분산이 아니다"라는 결론

법정 비유

F검정은 서로 다른 두 감정 결과가, 흔들리는 정도(분산)까지 똑같은지 맞대보는 교차검증입니다. 정규성이 의심스러운 증거라면, 정규분포를 가정하지 않는 Levene 검정이라는 대안 감정 도구를 대신 씁니다.

실습 핵심 정리
  • F = (s₁²/σ₁²) / (s₂²/σ₂²)
  • 두 집단의 등분산성 비교, ANOVA·회귀분석에서 응용
  • Levene: 정규성 가정 없이 등분산성 확인 가능

EXHIBIT O

ANOVA(분산분석)Analysis of Variance

t검정은 두 집단까지만 비교할 수 있습니다. 피고인이 세 명 이상이라면 어떻게 할까요. 이럴 때 쓰는 것이 분산분석(ANOVA)입니다. (t검정을 여러 번 반복해도 될 것 같지만, 반복할수록 우연히 유의한 결과가 나올 위험, 즉 1종 오류가 누적되어 커집니다 — 그래서 한 번에 검정하는 ANOVA를 씁니다.)

귀무가설 H₀
모든 집단의 평균은 같다
대립가설 H₁
적어도 하나의 집단 평균은 다르다

아이디어 — 집단 간 분산이 크고, 집단 내 분산이 작을수록 "차이가 있다"고 판단합니다. 이때 쓰는 검정통계량이 바로 Exhibit M에서 배운 F 통계량입니다 — ANOVA는 결국 F검정을 여러 집단으로 확장한 버전인 셈입니다.

일원분산분석
독립변수 1개, 3개 이상 그룹 비교 — 예: 광고 A/B/C의 구매금액 차이
이원분산분석
독립변수 2개 이상 — 주효과(캠페인 단독 효과)와 상호작용 효과(캠페인×성별의 조합 효과)를 함께 분석
추가 예제 ① 일원분산분석 — A/B/C 세 학급 각 10명의 시험 점수 평균을 비교합니다(귀무가설: 세 학급의 평균은 모두 같다).
python
groupA = [85, 92, 78, 88, 83, 90, 76, 84, 92, 87]
groupB = [79, 69, 84, 78, 79, 83, 79, 81, 86, 88]
groupC = [75, 68, 74, 65, 77, 72, 70, 73, 78, 75]

stats.f_oneway(groupA, groupB, groupC)
평균 85.5 / 80.6 / 72.7, F ≈ 16.88, p-value ≈ 0.00002 → p < 0.05, 귀무가설 기각 → 세 학급 중 적어도 한 곳은 평균이 다름
그런데, 어느 학급끼리 다른 걸까? ANOVA는 "적어도 하나는 다르다"까지만 알려줄 뿐, 어느 쌍이 다른지는 말해주지 않습니다. 이를 확인하려면 사후검정(Post-Hoc Test)이 필요합니다 — 모든 쌍을 하나하나 비교하면서도 반복 비교에 따른 1종 오류 누적을 보정해주는 절차입니다. 대표적으로 Tukey HSD와 Bonferroni 보정이 있습니다.
python
from statsmodels.stats.multicomp import pairwise_tukeyhsd

values = groupA + groupB + groupC
labels = ['A']*10 + ['B']*10 + ['C']*10
print(pairwise_tukeyhsd(values, labels, alpha=0.05).summary())
A - B 차이 -4.9 p-adj 0.089 → 유의하지 않음 A - C 차이 -12.8 p-adj <0.001 → 유의함 B - C 차이 -7.9 p-adj 0.004 → 유의함

즉 A반과 C반, B반과 C반은 확실히 다르지만, A반과 B반의 차이는 통계적으로 확신하기 어렵다는, ANOVA 하나만으로는 알 수 없던 세밀한 판결까지 내릴 수 있습니다. (표본 크기가 다르거나 등분산이 깨진 경우엔 Tukey 대신 Bonferroni 보정을 사용하기도 합니다.)

법정 비유

피고인이 세 명 이상인 사건에서, 각 피고인 그룹의 진술(평균)이 그룹 안에서는 비슷한데 그룹끼리는 확연히 다르다면 "그룹에 따라 뭔가 다르다"고 판단합니다. 이원분산분석은 여기서 한 걸음 더 나아가, "범행 도구"와 "범행 시간대"라는 두 가지 요인이 각각, 그리고 함께 결과에 영향을 주었는지까지 따지는 정밀 감정입니다.

추가 예제 ② 이원분산분석 — 매장 진열 방식(Decoration_Type)과 지역(Region)이 매출(Sales)에 영향을 주는지, 주효과와 상호작용을 함께 검정합니다.
python
from statsmodels.formula.api import ols
import statsmodels.api as sm

model = ols('Sales ~ C(Decoration_Type) * C(Region)', data=df).fit()
sm.stats.anova_lm(model)
C(Decoration_Type), C(Region) 행은 각 요인의 주효과를, C(Decoration_Type):C(Region) 행은 상호작용 효과를 나타냅니다. 각 행의 p-value가 0.05보다 작으면 그 요인(또는 조합)이 매출에 유의한 영향을 준다고 판단합니다.
전제조건은 t검정과 비슷합니다 — 각 집단이 정규분포를 따르고, 등분산성을 만족하며, 표본이 서로 독립이어야 합니다.
실전 핵심 정리
  • 3집단 이상 평균 비교 → ANOVA
  • 검정통계량 = F통계량
  • 일원 vs 이원(주효과 + 상호작용)
EXHIBIT P

지금까지는 "차이가 있는가"를 봤다면, 이번엔 두 연속형 변수가 함께 움직이는 정도(선형관계)를 잽니다. 상관계수 r은 −1 ~ 1 사이의 값을 가집니다.

r = 1 / −1
완전한 양(+) / 음(−)의 선형 상관
|r| 0.7~1.0
강한 상관
|r| 0.3~0.7
보통 정도 상관
|r| 0~0.3

귀무가설 H₀

법정 비유

피어슨 상관계수는 "두 증인의 증언이 같은 방향으로 흔들리는가"를 보는 감정입니다. 공부시간이 늘수록 시험 점수도 함께 느는 것처럼요. 다만 r=0이 나왔다고 해서 "아무 관계가 없다"고 단정할 수는 없습니다 — 관계가 휘어진(비선형) 형태일 수도 있기 때문입니다. 또 이 검정은 연속형·선형관계·이상치 없음을 전제로 하므로, 극단값 하나가 결과를 크게 흔들 수 있다는 점도 주의해야 합니다.

Spearman

python
from scipy.stats import spearmanr, kendalltau

  • 귀무가설: r = 0 (상관관계 없음)
  • 비선형·순서형 데이터 → Spearman, Kendall
EXHIBIT Q

크루스칼-왈리스 검정Kruskal-Wallis Test

ANOVA를 쓰고 싶은데, 표본이 정규분포를 따르지 않거나 등분산성이 깨졌다면 어떻게 할까요. 이럴 때 쓰는 것이 비모수검정(non-parametric test)인 크루스칼-왈리스 검정입니다. 값 자체가 아니라 순위(rank)만으로 비교하기 때문에, 정규성을 가정하지 않고 이상치나 작은 표본에도 강합니다. 다만 데이터가 실제로 정규분포를 따르는 상황이라면, ANOVA보다는 검정력이 다소 떨어집니다.

귀무가설 H₀
모든 그룹의 중앙값은 같다
대립가설 H₁

Investigator's Note

감정관의 사족 — 빅데이터 시대의 p-value

고전적 가설검정은 "모집단을 대표하는 작은 표본을 뽑아 검정한다"는 전제에서 출발합니다. 그런데 빅데이터 시대가 되면서, 표본이 아니라 사실상 모집단 전체에 가까운 수천만 건의 데이터를 통째로 분석하는 일이 흔해졌습니다.

법정 비유

증거가 수백만 건이면, 아주 사소한 흠집 하나조차 "통계적으로 유의미한 증거"로 잡히기 쉽습니다. 표본이 클수록 p-value는 거의 항상 작게 나오기 때문에, 미세한 차이조차 p < 0.05로 나와 "유의하다"고 판정되는 것이죠. 하지만 그 사소한 흠집이 정말 사건의 본질을 바꾸는지는 별개의 문제입니다.

따라서 빅데이터 분석에서는 "통계적으로 유의하다(p < α)"는 사실 하나만으로 충분하지 않습니다. 그 차이가 효과 크기(effect size)로 볼 때도 충분히 큰지, 도메인 지식에 비추어 실질적으로 의미 있는 차이(Practical Significance)인지를 함께 판단해야 합니다. p-value는 결론이 아니라, 무의미한 차이를 걸러내는 보조 도구로 쓰는 것이 안전합니다.

면적 계수 ≈ 1.80 (p < 0.001) → 유의미 층수 계수 ≈ 0.62 (p ≈ 0.369) → 유의미하지 않음 연차 계수 ≈ −1.37 (p ≈ 0.003) → 유의미 R² ≈ 0.920

흥미로운 지점은 층수입니다. 계수 자체는 양수(+0.62)지만 p-value가 0.05보다 훨씬 커서, "층수가 가격에 미치는 영향은 우연과 구분할 수 없다"고 판단합니다 — 변수가 여러 개일 때는 계수의 부호뿐 아니라 p-value로 유의성을 하나하나 확인해야 하는 이유가 바로 이것입니다.

범주형 변수는 어떻게? "지역", "아파트 등급"처럼 숫자가 아닌 변수는 pd.get_dummies(df, drop_first=True)로 0/1 더미 변수로 변환한 뒤 회귀식에 넣습니다. 기준이 되는 범주 하나는 빼는 것(drop_first)이 원칙입니다 — 그렇지 않으면 변수들이 서로 완전히 종속되어(다중공선성) 계산이 불안정해집니다.
