💡 왜 추천 시스템인가

상품·콘텐츠가 무한히 많은 시대, "고를 게 너무 많아 못 고르는" 문제가 생겼습니다. 추천 시스템은 사용자가 좋아할 만한 걸 먼저 골라 보여줘 매출·만족도를 끌어올리는 핵심 기술. 넷플릭스 시청의 80%가 추천에서 나온다고 해요.

추천의 두 갈래

무엇을 근거로 추천할까?

콘텐츠 기반 필터링

아이템의 속성이 비슷한 걸 추천

"액션 영화 봤네? → 다른 액션 영화"

아이템 정보(장르·키워드)만 있으면 OK

협업 필터링

사용자들의 평점 패턴으로 추천

"너랑 취향 비슷한 사람이 이것도 봤어"

다른 사용자들의 행동 데이터 활용

💡 비유 · 책 추천

콘텐츠 기반: "이 책이 SF니까, 다른 SF 책 추천". 협업 필터링: "당신과 독서 취향이 닮은 사람들이 이 책도 좋아했어요". 실무에선 둘을 섞어(하이브리드) 쓰는 경우가 많습니다.

협업 필터링의 두 방식

협업 필터링도 둘로 나뉜다

👥 최근접 이웃 방식

평점 데이터에서 유사도를 직접 계산. 사용자 기반 / 아이템 기반. 직관적이고 구현이 쉬움.

🔮 잠재 요인 방식

행렬 분해로 숨은 취향 요인을 추출. 대규모 데이터에 강하고 정확. 넷플릭스가 쓴 방식.

💡 큰 그림 정리

이 장의 구조: 콘텐츠 기반 → 협업 필터링(최근접 이웃) → 협업 필터링(잠재 요인=행렬 분해). 점점 정교해지는 순서로 배웁니다. 헷갈리면 이 지도를 떠올리세요!

콘텐츠 기반 필터링

"이 영화랑 비슷한 영화"를 추천. 8장의 벡터화와 코사인 유사도가 활약합니다.

콘텐츠 기반 개념

아이템의 '내용'으로 닮은 것 찾기

  • 아이템의 속성(장르·키워드 등)을 벡터로
  • 아이템끼리 코사인 유사도 계산
  • 가장 비슷한 아이템을 추천
💡 비유 · 음악 추천

"잔잔한 발라드"를 들으면, 장르·분위기·악기가 비슷한 다른 곡을 추천하는 것. 다른 사람의 취향은 전혀 보지 않고, 오직 콘텐츠 자체의 닮음만 봅니다.

📌 장점: 새 사용자에게도 바로 추천 가능(다른 사용자 데이터 불필요). 단점: 비슷한 것만 추천돼 다양성이 부족할 수 있음.

사용자 기반

💡 비유 · "이 상품을 산 사람들이..."

쇼핑몰의 "이 상품을 구매한 분들이 함께 본 상품"이 바로 아이템 기반 협업 필터링! 사용자 취향은 자주 변하지만 아이템 간 관계는 안정적이라, 실무에선 아이템 기반을 더 많이 씁니다.

실습 · 아이템 기반 협업 필터링

영화 간 유사도로 추천

# ① 사용자-영화 평점 행렬 만들기 (pivot_table) ratings_matrix = ratings.pivot_table('rating', index='userId', columns='title').fillna(0) # ② 영화 간 코사인 유사도 (행렬을 전치 후 계산) item_sim = cosine_similarity(ratings_matrix.T, ratings_matrix.T) # → '내가 본 영화와 비슷한 영화' 중 안 본 것을 추천
💡 또 코사인 유사도!

콘텐츠 기반에선 '장르 벡터'로, 협업 필터링에선 '평점 벡터'로 유사도를 잽니다. 대상만 다를 뿐 같은 도구(코사인 유사도)예요. 한 번 배운 개념이 계속 재활용되죠.

SECTION 04 · 07

잠재 요인 협업 필터링 — 행렬 분해

평점 뒤에 숨은 '취향 요인'을 수학으로 찾아냅니다. 넷플릭스 우승의 비결.

잠재 요인이란

평점 뒤에 숨은 '취향 요인'

사람들이 영화에 준 평점 뒤에는 '얼마나 액션을 좋아하나', '로맨스 선호도' 같은 숨은 요인이 있습니다. 이걸 잠재 요인이라 해요.

💡 비유 · MBTI 같은 숨은 성향

겉으로 드러난 행동(평점) 뒤엔 드러나지 않은 성향(잠재 요인)이 있죠. 사용자의 '액션 선호도'와 영화의 '액션 정도'가 맞으면 높은 평점! 이 숨은 요인을 찾으면 안 본 영화 평점도 예측할 수 있습니다.

🔑 어떻게 찾을까? → 평점 행렬을 두 개의 작은 행렬로 쪼개는 '행렬 분해'로! (6장 SVD의 연장선)

💡 비유 · 빈칸 추론

구멍 뚫린 평점표(R)를 '사용자 성향(P)'과 '아이템 특성(Q)' 두 표로 분해합니다. 그럼 두 표를 다시 곱해 빈칸(안 본 영화의 평점)까지 추정할 수 있어요! 이 추정 평점이 높은 영화를 추천합니다.

📌 잠재 요인 개수 K를 정해 P, Q의 크기를 결정합니다. (예: K=3개 요인)

경사 하강법으로 분해

P와 Q를 어떻게 찾을까?

  • P, Q를 랜덤값으로 시작
  • 실제 평점과 예측(P×Q) 오차를 경사 하강법으로 줄임
  • 반복하면 빈칸을 잘 채우는 P, Q 완성
💡 5장과 연결!

P, Q를 찾는 방법이 바로 경사 하강법(5장)입니다. "오차를 줄이는 방향으로 조금씩 수정"하는 그 원리 그대로예요. 머신러닝의 핵심 도구가 추천에서도 또 등장합니다.

Surprise — 추천 전용 패키지

복잡한 행렬 분해를, 사이킷런처럼 쉽게. 추천 시스템의 도구상자.

Surprise 패키지

추천을 fit/predict로 — Surprise

from surprise import SVD, Dataset, accuracy from surprise.model_selection import train_test_split data = Dataset.load_builtin('ml-100k') # 영화 평점 데이터 trainset, testset = train_test_split(data, test_size=0.25) algo = SVD() # 행렬 분해 알고리즘 algo.fit(trainset) # 학습 algo.predict(uid, iid) # 특정 사용자의 특정 영화 평점 예측
💡 사이킷런과 닮은 사용법

Surprise는 추천 전용 라이브러리지만, fit → predict 패턴은 사이킷런과 똑같아요. 앞서 직접 구현한 행렬 분해(SVD)를 한 줄로 쓸 수 있게 해주고, RMSE로 평가까지 됩니다. 실무에서 추천 프로토타입을 빠르게 만들 때 유용.
