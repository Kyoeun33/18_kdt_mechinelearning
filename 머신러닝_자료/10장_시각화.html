SECTION 02

Matplotlib — 시각화의 기반

Figure와 Axes라는 두 개념만 잡으면, 나머지는 응용입니다.

pyplot 기초

가장 단순한 그래프 그리기

import matplotlib.pyplot as plt plt.plot([1, 2, 3], [2, 4, 6]) # x값, y값 plt.title("Hello plot") # 제목 plt.show() # 화면에 출력
💡 plt.show()는 왜?

그래프를 '다 그렸으니 이제 보여줘'라고 명령하는 마침표 같은 것. 주피터 노트북에선 생략해도 보이지만, 습관적으로 붙이는 게 좋아요. as plt는 1장에서 본 '별명' 약속!

Figure와 Axes

도화지(Figure)와 그림틀(Axes)

# Figure(전체 그림)와 Axes(그래프 영역)를 함께 fig, ax = plt.subplots(figsize=(4,4)) ax.plot([1,2,3], [2,4,6]) ax.set_title('Hello plot')
💡 비유 · 액자와 그림

Figure = 전체 도화지(액자), Axes = 그 안의 실제 그래프 한 칸. 도화지 하나에 그래프 여러 칸(Axes)을 넣을 수 있어요. figsize로 도화지 크기를 정합니다.

📌 ax.set_title()처럼 Axes에 점(.)으로 명령. 이 'fig, ax' 방식이 복잡한 그래프를 다루는 정석이에요.

여러 개의 그래프 · subplot

한 화면에 여러 그래프

# 1행 2열로 그래프 영역 2개 만들기 fig, (ax1, ax2) = plt.subplots(nrows=1, ncols=2, figsize=(6,3)) ax1.plot(...) # 왼쪽 그래프 ax2.bar(...) # 오른쪽 그래프
💡 비유 · 격자 노트

nrows·ncols로 도화지를 격자로 나눕니다. "2×2면 그래프 4칸". 여러 그래프를 나란히 비교할 때 필수예요. 각 칸(ax1, ax2...)에 따로 그리면 됩니다.

🔑 데이터 탐색(EDA) 때 여러 피처를 한눈에 비교하려고 subplot을 정말 많이 씁니다.

그래프 꾸미기

색·마커·축·범례 더하기

# 색, 마커, 선 스타일 지정 plt.plot(x, y, color='red', marker='o', linestyle='dashed', linewidth=2) plt.xlabel('x axis'); plt.ylabel('y axis') # 축 이름 plt.legend() # 범례 (어떤 선이 무엇인지) plt.xticks(rotation=45) # 축 눈금 회전
💡 좋은 그래프의 조건

예쁜 색보다 중요한 건 축 이름·제목·범례입니다. 이게 없으면 "이 숫자가 뭐지?" 하고 헷갈리죠. "누가 봐도 이해되는 그래프"가 목표. 보는 사람을 배려하는 게 시각화의 핵심이에요.

SECTION 03

Seaborn — 예쁘고 간편하게

DataFrame을 바로 넣으면, 짧은 코드로 멋진 통계 그래프가 나옵니다.

차트 선택 가이드 (중요!)

데이터에 맞는 그래프 고르기

알고 싶은 것데이터 종류추천 그래프
값의 분포연속형 (나이 등)히스토그램, KDE, 박스, 바이올린
개수 세기범주형 (등급 등)카운트 플롯
그룹별 비교범주 × 수치바 플롯
두 값의 관계연속 × 연속산점도
변수 간 상관여러 수치상관 히트맵

🔑 "무엇을 보여주고 싶은가?"가 그래프를 결정합니다. 이 표가 평생 치트시트가 될 거예요.

분포 보기

히스토그램 — 값이 어떻게 퍼져 있나

import seaborn as sns # 나이 분포를 막대로, kde=True로 곡선도 sns.histplot(x='Age', data=titanic_df, bins=30, kde=True)
💡 비유 · 키 순서로 줄 세우기

나이대별로 몇 명인지 구간(bins)으로 나눠 막대로 보여줍니다. "20~30대가 가장 많네!"가 한눈에 보이죠. kde는 그 위에 부드러운 분포 곡선을 덧그립니다.

📌 데이터를 처음 받으면 분포부터 그려보는 게 기본. 이상치·치우침을 바로 발견할 수 있어요. (3장 피마 '0값' 발견처럼!)

카운트 & 바 플롯

개수 세기 vs 그룹별 평균

countplot — 개수

sns.countplot(x='Pclass', ...)

"1등석/2등석/3등석 승객이 각각 몇 명?"

barplot — 평균(집계)

sns.barplot(x='Pclass', y='Survived')

"등급별 평균 생존율은?"

💡 헷갈리지 마세요

countplot은 x 하나만 받아 건수를 셉니다. barplot은 x(범주)와 y(수치)를 받아 그룹별 평균(기본값)을 막대로 보여줘요. "몇 개인가" vs "평균이 얼마인가"의 차이!

hue로 세분화

hue — 한 차원 더 쪼개 보기

# 등급별 생존율을, 성별로 또 나눠서 sns.barplot(x='Pclass', y='Survived', hue='Sex', data=titanic_df)
💡 비유 · 색깔로 구분

hue는 막대를 또 다른 기준(성별)으로 색깔 분리합니다. "1등석에서도 여성이 남성보다 생존율이 훨씬 높네!" 같은 숨은 패턴이 드러나요. 거의 모든 Seaborn 그래프에 hue를 쓸 수 있습니다.

🔑 hue는 2차원 정보를 한 그래프에 담는 강력한 도구. EDA에서 인사이트를 캐낼 때 단골입니다.

박스 플롯 & 바이올린 플롯

분포를 요약해서 비교하기

박스 플롯

중앙값·사분위·이상치를 상자로

sns.boxplot(x='Pclass', y='Age')

바이올린 플롯

박스 + 분포 모양(곡선)까지

sns.violinplot(x='Pclass', y='Age')

💡 비유 · 건강검진 요약표

박스 플롯은 데이터를 '최소·중간·최대·이상치'로 요약한 5줄 요약. 바이올린은 거기에 "어느 구간에 많이 몰렸나"까지 보여주는 업그레이드 버전. 그룹별 분포 비교에 최고예요. (4장 이상치 IQR과 연결!)

산점도 & 상관 히트맵

관계와 상관을 한눈에

🔵 산점도 (Scatter)

두 연속 변수의 관계를 점으로. "나이가 많을수록 요금이 비싼가?"

sns.scatterplot(x, y, data)

🟥 상관 히트맵

여러 변수 간 상관계수를 색으로. 진할수록 강한 관계.

sns.heatmap(df.corr(), annot=True)

💡 히트맵 = 관계 지도

피처가 많을 때, 어떤 변수끼리 강하게 연관되는지 색으로 한눈에 봅니다. 빨강(강한 양의 상관)·파랑(음의 상관). 피처 선택·다중공선성 점검에 필수 도구예요.
