오늘의 지도

SECTION 01

K-평균 알고리즘

군집화의 출발점이자 가장 널리 쓰이는 알고리즘. 중심점을 옮겨가며 그룹을 만듭니다.

군집화란

분류와 군집화, 헷갈리지 말기

분류 (4장, 지도학습)

정답(라벨)이 있음

"이건 개, 이건 고양이" 미리 배움

군집화 (7장, 비지도학습)

정답이 없음

"비슷한 것끼리" 스스로 묶음

💡 비유 · 빨래 정리

분류는 "흰옷 칸·색옷 칸이 정해져 있고 거기 맞춰 넣기". 군집화는 "정해진 칸 없이, 비슷한 옷끼리 알아서 더미를 만들기". 묶은 다음 "아, 이 더미는 운동복이네"라고 의미를 붙이는 건 사람의 몫이에요.

K-평균

K-평균 — 중심점을 옮겨가며 묶기

① 중심 K개
아무 데나 찍기
→
② 할당
가까운 중심에 소속
→
③ 이동
중심을 무리 가운데로
→
④ 반복
안 변할 때까지
💡 비유 · 푸드트럭 위치 정하기

손님이 흩어진 광장에 푸드트럭 3대를 둘 때, ① 일단 아무 데나 세우고 → ② 손님은 가까운 트럭으로 → ③ 트럭은 모인 손님 중앙으로 이동 → ④ 반복. 결국 가장 효율적인 위치(군집 중심)에 자리 잡습니다.

📌 K = 군집 개수(트럭 대수)로, 사람이 미리 정해야 합니다. (이게 K-평균의 숙제!)

K-평균 코드 & 한계

코드는 쉽지만, 약점도 있다

from sklearn.cluster import KMeans kmeans = KMeans(n_clusters=3, init='k-means++', random_state=0) kmeans.fit(irisDF) print(kmeans.labels_) # 각 데이터가 어느 군집인지 (0/1/2)
⚠️ K-평균의 약점

① K를 미리 정해야 함 (몇 개로 묶을지 모를 때 곤란) ② 군집이 '동그란 모양'이라고 가정 → 길쭉하거나 복잡한 모양엔 약함. 그래서 뒤의 GMM·DBSCAN이 등장합니다.

📌 k-means++: 초기 중심을 똑똑하게 찍어 결과를 안정시키는 기본 옵션이에요.

SECTION 02

군집 평가 — 실루엣 분석

정답이 없는데, 잘 묶였는지 어떻게 판단할까요? 그리고 K는 몇 개가 좋을까요?

군집 평가의 어려움

정답이 없으니 '정확도'를 못 쓴다

분류는 정답과 비교해 정확도를 쟀지만, 군집화는 정답이 없어요. 그럼 "잘 묶였다"를 어떻게 정의할까요?

👥 응집도

같은 군집 안의 데이터끼리 얼마나 가까운가 (뭉쳐 있을수록 좋음)

↔️ 분리도

다른 군집과 얼마나 멀리 떨어졌나 (멀수록 좋음)

🔑 좋은 군집 = "안은 빽빽하고(응집), 밖과는 멀리(분리)". 이 둘을 한 숫자로 합친 게 실루엣 계수입니다.

실루엣 분석

실루엣 계수 — -1에서 +1까지

  • +1에 가까움: 아주 잘 묶임 👍
  • 0 근처: 군집 경계에 걸침
  • 음수: 잘못 묶임 (다른 군집이 더 가까움)
from sklearn.metrics import silhouette_score silhouette_score(X, labels) # 전체 평균
💡 비유 · 동아리 소속감

"내 동아리 사람들과는 친하고(응집), 다른 동아리와는 거리가 있다(분리)"면 소속이 분명한 거죠. 실루엣 계수가 높다는 건 각 데이터가 자기 군집에 잘 어울린다는 뜻입니다.

최적의 K 찾기

K를 몇 개로 할지, 실루엣으로 결정

K를 2, 3, 4, 5...로 바꿔가며 실루엣 점수를 비교하고, 가장 높으면서 군집들이 고르게 잘 나뉘는 K를 고릅니다.

💡 실무 접근

실루엣 점수만 맹신하진 않아요. 비즈니스적으로 의미 있는 개수(예: 고객을 3~5 등급으로)인지도 함께 봅니다. 숫자 + 현실 감각의 조합!

📌 군집별 실루엣 면적을 그래프로 그려, 크기가 들쭉날쭉하지 않고 고른 K가 좋은 선택입니다. (visualize_silhouette 함수)

SECTION 03

평균 이동 (Mean Shift)

K를 정할 필요 없이, '데이터가 가장 빽빽한 곳'을 스스로 찾아갑니다.

평균 이동

밀도가 높은 봉우리를 찾아서

  • 데이터가 가장 밀집한 곳(밀도 봉우리)으로 점들이 이동
  • K를 정할 필요 없음 — 군집 수를 자동으로 찾음
  • bandwidth(탐색 반경)가 핵심 파라미터
💡 비유 · 사람 많은 쪽으로

축제장에서 눈을 감고 "사람 소리가 더 큰 쪽"으로 계속 걸으면 결국 가장 붐비는 곳에 도달하죠. 평균 이동은 각 점이 주변에서 가장 붐비는 중심으로 모여드는 방식입니다.

from sklearn.cluster import MeanShift, estimate_bandwidth bandwidth = estimate_bandwidth(X) # 최적 반경 자동 추정 ms = MeanShift(bandwidth=bandwidth)

SECTION 04

GMM — 가우시안 혼합 모델

"딱 잘라" 묶는 K-평균과 달리, 확률로 부드럽게 묶습니다.

GMM 개요

GMM = 여러 정규분포의 혼합

K-평균

거리 기반으로 딱 잘라 할당

군집이 동그랗다고 가정

길쭉한 군집엔 약함

GMM

확률 분포 기반으로 부드럽게

군집이 길쭉/타원형이어도 OK

"이 점은 군집A일 확률 80%"

💡 비유 · 키 분포로 성별 추정

남녀 키는 각각 종 모양 분포를 이룹니다. 170cm인 사람은 "남자일 확률 70%, 여자일 확률 30%"처럼 추정 가능하죠. GMM은 데이터가 여러 정규분포의 섞임이라 보고 각 군집 소속 확률을 계산합니다.

GMM vs K-평균

길쭉한 데이터에서 진가 발휘

from sklearn.mixture import GaussianMixture gmm = GaussianMixture(n_components=3, random_state=0) labels = gmm.fit_predict(iris.data)
💡 언제 GMM이 유리한가

데이터가 동그랗지 않고 길게 늘어진 모양일 때, K-평균은 어색하게 자르지만 GMM은 그 형태를 따라 자연스럽게 묶습니다. 단, K-평균보다 계산이 무거워요.

📌 n_components = 섞인 분포의 개수(=군집 수). K-평균의 n_clusters와 비슷한 역할이에요.

SECTION 05

DBSCAN — 밀도 기반 군집화

동그란 모양도, K도 필요 없어요. 데이터의 '밀도'만 보고 복잡한 모양도 척척.

DBSCAN

밀도로 묶고, 외톨이는 노이즈로

  • 빽빽하게 모인 점들을 하나의 군집으로
  • K를 정할 필요 없음 (자동)
  • 초승달·소용돌이 같은 복잡한 모양도 OK
  • 어디에도 안 속한 점은 노이즈(-1)로 분리
💡 비유 · 별자리 잇기

밤하늘에서 가까이 모인 별들을 이어 별자리를 만들고, 외딴 별은 그냥 두는 것. DBSCAN은 촘촘한 영역을 군집으로, 동떨어진 점은 이상치(노이즈)로 자동 처리합니다.

from sklearn.cluster import DBSCAN dbscan = DBSCAN(eps=0.6, min_samples=8) # eps=반경, min_samples=최소 이웃 수
군집화 알고리즘 비교

SECTION 06

실습 — 고객 세그먼테이션

온라인 쇼핑몰 거래 데이터로 '비슷한 고객 그룹'을 찾아 마케팅에 활용합니다.

고객 세그먼테이션 & RFM

고객을 'RFM'으로 이해하기

R · Recency

최근성 — 얼마나 최근에 구매했나

F · Frequency

빈도 — 얼마나 자주 구매했나

M · Monetary

금액 — 얼마나 많이 썼나

💡 비유 · 단골 손님 알아보기

가게 주인은 손님을 "자주 와서 많이 사는 VIP", "옛날에 한 번 온 뜨내기"처럼 나눠 기억하죠. RFM은 이 직관을 3개의 숫자로 만든 것. 이 숫자로 고객을 군집화하면 마케팅 전략이 보입니다.

데이터 가공 & 군집화

거래 기록 → 고객별 RFM → 군집

# 거래 데이터를 고객별로 집계해 RFM 만들기 agg = {'InvoiceDate':'max', # Recency (최근 구매일) 'InvoiceNo':'count', # Frequency (구매 횟수) 'sale_amount':'sum'} # Monetary (총 구매액) cust_df = retail_df.groupby('CustomerID').agg(agg) # → KMeans로 고객 군집화 → 그룹별 마케팅
⚠️ 실무 포인트 — 왜곡된 분포

RFM은 소수 VIP가 매우 큰 값을 가져 분포가 크게 치우칩니다. 그래서 로그 변환(5장 복습!) 후 군집화하면 결과가 훨씬 좋아져요. 데이터 정제가 여기서도 핵심!

7장 핵심 정리

오늘의 한 페이지 요약

🎯K-평균

중심점 거리로 묶기. K를 정해야 하고 동그란 군집 가정. 가장 기본.

📏군집 평가

정답이 없어 실루엣 계수(응집+분리)로 평가. 최적 K도 결정.

🔀다양한 기법

평균이동(밀도 봉우리·K자동), GMM(확률·길쭉), DBSCAN(밀도·복잡한 모양·노이즈).

🛍️실전

RFM으로 고객 세그먼테이션. 로그 변환 후 군집화.

✅ 정답 없이도 데이터의 숨은 구조를 찾는 법을 배웠습니다. 군집화는 고객 분석·이상 탐지·추천 등 실무에서 정말 많이 쓰여요!
