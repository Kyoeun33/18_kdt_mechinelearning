SECTION 01-03

회귀의 기초 — 직선과 경사 하강법

데이터를 가장 잘 설명하는 '직선'을 어떻게 찾을까? 회귀의 심장을 들여다봅니다.

회귀 소개

회귀 = 점들 사이로 최적의 선 긋기

공부 시간(X)과 점수(y)의 점들을 가장 잘 관통하는 직선을 찾으면, 새 학생의 공부 시간으로 점수를 예측할 수 있어요.

y = w₁·X + w₀ # w₁ = 기울기, w₀ = 절편 (이 둘을 학습)
💡 비유 · 산점도 위의 자

흩어진 점들 위에 투명한 자를 올려놓고, 모든 점에서 가장 가까운 위치로 기울기·높이를 조절하는 것. 그 '가장 잘 맞는 자'가 바로 회귀 직선입니다.

📌 "가장 잘 맞는다" = 실제값과 예측값의 오차(거리)가 가장 작다. 이걸 어떻게 찾을까요? → 경사 하강법!

비용 최소화

'잘 맞는 정도'를 숫자로 — 비용 함수

비용(MSE) = 평균( (실제값 − 예측값)² )
💡 비유 · 과녁과의 거리

예측이 실제와 얼마나 빗나갔는지를 거리의 제곱으로 합산한 게 비용입니다. 비용이 작을수록 좋은 직선. 회귀 학습이란 결국 이 비용을 가장 작게 만드는 기울기·절편을 찾는 것이에요.

📌 제곱하는 이유: 음수·양수 오차가 상쇄되지 않게, 그리고 큰 오차에 더 큰 벌점을 주려고.

경사 하강법 (Gradient Descent)

비용을 줄이는 법 — 한 걸음씩 내려가기

💡 비유 · 안갯속 하산

짙은 안개 속 산에서 가장 낮은 곳(최소 비용)으로 내려가려면? 발밑에서 가장 가파르게 내려가는 방향으로 한 걸음씩 이동하면 됩니다. 경사 하강법이 바로 이거예요.

  • 비용이 줄어드는 방향으로 기울기·절편을 조금씩 수정
  • 학습률(learning_rate) = 한 걸음의 크기
  • 이를 수천 번 반복 → 최적값 도달
⚠️ 학습률 주의

걸음이 너무 크면(높은 학습률) 최저점을 지나쳐 발산하고, 너무 작으면 한없이 느립니다. 적절한 보폭이 중요해요. 딥러닝의 핵심 원리이기도 합니다!

SECTION 04

사이킷런 LinearRegression

캘리포니아 집값 데이터로 첫 회귀 모델을. 그리고 회귀는 '어떻게 평가'하는지 배웁니다.

회귀 평가지표

회귀는 '얼마나 빗나갔나'로 평가한다

MSE

오차 제곱의 평균

RMSE

MSE의 제곱근. 단위가 원래대로 돌아와 해석 쉬움 ⭐

MAE

오차 절댓값의 평균

R² (결정계수)

1에 가까울수록 잘 설명. 0~1

💡 분류와의 차이

분류는 "맞았나/틀렸나"(정확도)였지만, 회귀는 "얼마나 가깝게 맞혔나"(오차)로 평가합니다. 집값을 1000만원 차이로 맞혔는지, 1억 차이인지가 중요하니까요. RMSE가 가장 많이 쓰여요.

캘리포니아 주택 가격 예측

코드로 보기 — 익숙한 fit/predict

from sklearn.datasets import fetch_california_housing from sklearn.linear_model import LinearRegression from sklearn.metrics import mean_squared_error, r2_score lr = LinearRegression() lr.fit(X_train, y_train) # 분류와 똑같은 fit/predict! y_pred = lr.predict(X_test) rmse = np.sqrt(mean_squared_error(y_test, y_pred)) # RMSE print(r2_score(y_test, y_pred)) # R² → 0.595
⚠️ 교재의 보스턴 데이터는 이제 못 씁니다

책은 보스턴 집값(load_boston)을 쓰지만, 이 데이터는 윤리적 문제로 사이킷런 1.2에서 완전히 제거됐습니다. 실습 코드는 캘리포니아 집값(fetch_california_housing)으로 대체했어요. 피처 8개(소득·주택연식·방수·위경도 등), 20,640건입니다.

💡 회귀 계수 해석 (보너스)

선형 회귀는 각 피처의 회귀 계수(coef_)를 줍니다. 캘리포니아 데이터에선 "소득 중앙값(MedInc)이 높을수록 집값↑(+0.43), 북쪽·동쪽으로 갈수록 집값↓(위도 −0.43, 경도 −0.44)"처럼 영향 방향과 크기를 해석할 수 있어요.

회귀의 교차 검증

cross_val_score, 부호에 주의!

# 회귀의 교차 검증 — scoring에 neg_mean_squared_error neg_mse = cross_val_score(lr, X, y, scoring="neg_mean_squared_error", cv=5) rmse = np.sqrt(-1 * neg_mse) # 음수라서 -1 곱해 양수로!
⚠️ 왜 'neg'(음수)일까?

사이킷런은 "점수는 클수록 좋다"는 규칙을 따릅니다. 그런데 오차(MSE)는 작을수록 좋죠. 그래서 부호를 뒤집어 음수(neg)로 반환합니다. 우리가 다시 -1을 곱해 원래 값으로 되돌려요. 처음엔 헷갈리는 단골 함정!

SECTION 05

다항 회귀와 과적합

직선으로 안 되면 곡선으로. 하지만 너무 구불구불하면? 머신러닝 최대의 적, 과적합을 만납니다.

다항 회귀

직선 대신 곡선 — 다항 회귀

데이터가 곡선 모양이면 직선으론 부족하죠. 피처를 제곱·세제곱한 항을 추가하면 곡선도 표현할 수 있어요.

from sklearn.preprocessing import PolynomialFeatures poly = PolynomialFeatures(degree=2) # 2차항 추가
💡 비유 · 자에서 줄자로

직선 자로는 곡선을 못 그리지만, 휘어지는 줄자라면 가능하죠. degree(차수)가 높을수록 더 구불구불한 곡선을 그릴 수 있습니다. 단, 다음 슬라이드의 함정 주의!

📌 보통 Pipeline으로 [다항 변환 → 선형 회귀]를 한 번에 묶어 처리합니다.

과소적합 vs 과적합

차수가 높다고 좋은 게 아니다

Degree 1 · 과소적합
너무 단순 — 패턴을 못 잡음
Degree 4 · 적절 ✓
패턴은 잡고 노이즈는 무시
Degree 15 · 과적합
노이즈까지 외움 — 새 데이터 취약

🔑 너무 단순하면 과소적합, 너무 복잡하면 과적합. 그 사이 적절한 균형점을 찾는 게 핵심입니다.

편향-분산 트레이드오프

편향과 분산, 영원한 줄다리기

높은 편향 (과소적합)

모델이 너무 단순해 일관되게 틀림

핵심 패턴조차 못 잡음

높은 분산 (과적합)

데이터가 조금만 바뀌어도 예측이 크게 출렁

학습 데이터만 잘 맞춤

💡 비유 · 다트판

높은 편향: 화살이 한곳에 모이지만 과녁에서 빗나감(일관되게 틀림). 높은 분산: 사방에 흩어짐(들쭉날쭉). 좋은 모델은 과녁 중앙에 모이게 — 둘의 균형을 맞춥니다.

SECTION 06

규제 선형 모델 — 릿지·라쏘·엘라스틱넷

과적합을 막는 영리한 장치. 모델에게 "너무 욕심내지 마"라고 제동을 겁니다.

규제(Regularization)

규제 — 회귀 계수에 제동 걸기

과적합된 모델은 회귀 계수가 비정상적으로 커지는 경향이 있어요. 규제는 계수가 너무 커지지 않도록 벌점을 줍니다.

  • alpha: 규제 강도 (클수록 강하게 제동)
💡 비유 · 과외 선생님

"이 점들에 무조건 다 맞춰!"가 아니라, "적당히 단순하게 가, 욕심 부리지 마"라고 옆에서 잡아주는 코치. 그 결과 새 데이터에도 잘 통하는 일반화된 모델이 됩니다.

세 가지 규제 모델

릿지 · 라쏘 · 엘라스틱넷

릿지 (Ridge)

계수를 작게 줄임 (L2)

0이 되진 않음

무난한 기본 선택

라쏘 (Lasso)

불필요한 계수를 0으로 (L1)

= 피처 선택 효과

중요한 피처만 남김

엘라스틱넷

릿지 + 라쏘 혼합

두 장점 절충

피처 많을 때 유용

💡 비유 · 짐 줄이기

릿지는 모든 짐을 조금씩 가볍게, 라쏘는 안 쓰는 짐을 아예 버림(0으로). 라쏘는 그래서 "어떤 피처가 중요한가"를 자동으로 골라줍니다.

alpha 효과

규제 강도(alpha) 조절해보기

from sklearn.linear_model import Ridge # alpha를 0 → 100으로 키우며 RMSE 비교 for alpha in [0, 0.1, 1, 10, 100]: ridge = Ridge(alpha=alpha) # cross_val_score로 평균 RMSE 측정 → 적절한 alpha 탐색
💡 핵심 직관

alpha=0이면 규제 없음(=일반 선형 회귀). alpha를 키울수록 계수들이 0 쪽으로 눌려 모델이 단순해집니다. 너무 크면 과소적합. 적절한 alpha를 교차 검증으로 찾는 게 정석이에요.

📌 선형 회귀 전에 스케일링·로그 변환을 하면 규제 모델 성능이 더 좋아지는 경우가 많습니다.

SECTION 07-08

로지스틱 회귀 & 회귀 트리

이름에 속지 마세요. 그리고 4장의 트리들이 회귀로 변신합니다.

로지스틱 회귀

'회귀'라는 이름의 분류 모델 🤯

⚠️ 이름의 함정

로지스틱 '회귀'는 숫자가 아니라 범주(0/1)를 예측하는 분류 모델입니다! 선형 회귀에 시그모이드 함수를 씌워 '확률'을 출력하게 만든 것이라 이름에 회귀가 붙었어요.

from sklearn.linear_model import LogisticRegression lr = LogisticRegression() # 유방암 분류 → accuracy 0.977, AUC 0.995
💡 기억할 점

실무에서 분류의 baseline으로 자주 씁니다. 빠르고, 해석 쉽고, 확률을 주니까요. 3·4장의 분류 실습에서 이미 만났던 친구!

회귀 트리

트리로 숫자 예측하기

4장의 트리 모델들은 회귀 버전도 있어요. 잎 노드에서 분류 대신 평균값을 예측합니다.

DecisionTreeRegressor RandomForestRegressor XGBRegressor, LGBMRegressor
💡 비유 · 계단식 예측

선형 회귀가 매끈한 직선/곡선이라면, 회귀 트리는 계단 모양으로 예측합니다. "소득 3만 달러 구간은 평균 15만, 5만 달러 구간은 평균 22만"처럼 구간별 평균을 내는 거예요.

🔑 분류는 Classifier, 회귀는 Regressor. 사이킷런은 이렇게 짝을 이뤄요. 캘리포니아 집값에서도 트리 계열(RMSE 0.63~0.65)이 선형 회귀(0.746)보다 좋은 성능을 냅니다.

# 날짜를 쪼개 새 피처 만들기 df['hour'] = df.datetime.apply(lambda x: x.hour) df['month'] = df.datetime.apply(lambda x: x.month)
💡 피처 엔지니어링의 힘

"2011-01-20 08:00"이라는 한 덩어리보다, '8시', '1월', '겨울'로 쪼개면 모델이 패턴을 훨씬 잘 잡습니다. 출퇴근 시간대 수요 급증 같은 걸요. 좋은 피처가 좋은 모델을 만듭니다.

로그 변환의 위력

타깃이 한쪽으로 쏠려 있을 때

💡 비유 · 고무줄 펴기

대여량·집값처럼 대부분 작고 일부만 매우 큰 데이터는 분포가 한쪽으로 쏠립니다. 로그 변환(np.log1p)은 큰 값을 꾹 눌러 고르게 펴줘, 모델이 더 잘 학습하게 합니다.

# 타깃을 로그 변환 후 학습 y_log = np.log1p(y) # 예측 후엔 다시 원래 스케일로 pred = np.expm1(model.predict(X))
⚠️ 잊지 마세요

로그로 변환해 학습했다면, 예측값은 expm1로 되돌려야 실제 단위가 됩니다. log1p ↔ expm1은 짝꿍이에요. (4장 신용카드 로그 변환과 같은 기법!)

예측 결과 혼합 & 스태킹

여러 모델을 섞어 마지막 한 방울까지

  • 혼합(Blending): 여러 모델 예측을 가중 평균 (예: 릿지 0.4 + 라쏘 0.6)
  • 스태킹: 예측들을 메타 모델의 입력으로 (4장 복습)
💡 비유 · 여러 일기예보 종합

한 방송사 예보보다 여러 예보를 종합하면 더 정확하죠. 회귀에서도 서로 다른 모델의 예측을 섞으면 단일 모델보다 안정적이고 정확해집니다.

🔑 캐글 상위권의 비밀: 좋은 단일 모델 + 여러 모델의 앙상블/혼합. 마지막 0.1%를 짜내는 기법이에요.
